# TikTok Minis 官方 Player 接入

## 生产合同

本节只描述固定 tiktok_minis 应用，其播放入口是 `TTMinis.getPlayer("byteplus")`；该分支不加载独立 SDK、不创建原生 HTML Video、不接收 DirectUrl、MP4、DRM KEK 或长期播放凭据。byteplus_web 应用走 [独立 VePlayer 适配器](veplayer-direct.md)，两通道共用页面、登录、广告和权益。

服务端权益校验成功后返回：

- `channel`: 固定为 `byteplus`。
- `albumId`: TikTok 审核通过的 Album 字符串标识。
- `episodeId`: TikTok 审核通过的 Episode 字符串标识。
- `vid`: BytePlus VOD 媒资字符串标识。

官方分支不使用 playAuthToken、clientVersion 或旧 play_token；直连短时 Token 是独立合同，不转换成官方凭据。最低 SDK/TikTok 版本须按当前官方发布规范在设备验收时确认，本次未新增包内版本门禁。

## 播放流程

1. `index.html` 用当前应用 `clientKey` 初始化 TikTok Minis SDK。
2. 完成 TikTok 静默登录，Runtime 缓存 `getPlayer("byteplus")` 的构造器；生产与预发登录失败时只允许浏览公开目录，个人库、播放和奖励必须等待可信身份。
3. 播放页向消费者 API 提交内部 `dramaId`、`episodeId`；不提交平台媒资标识；X-Mini-Version 仅用于应用审核配置匹配，不参与媒资或权益授权。
4. 服务端读取当前应用拥有或已授权的线上快照，校验媒资和用户权益；编辑草稿不参与播放。
5. 服务端直接返回 Player 描述符，不创建取证会话，不下发视频 URL 或播放 Token。
6. H5 使用官方标识创建 Player，并通过 `getVideoByToken.needPoster=true` 使用 VID 在 BytePlus 中的视频封面；切集时在同一实例调用 `playNext`，继续传入相同封面配置。
7. 字幕解析固定关闭（`autoSubtitle: false`），忽略官方 `Subtitle` 插件；播放器控件语言固定为 `en`。

TikTok Minis 官方 Player 不要求 VePlayer License，也不加载项目中供直连分支使用的独立 npm SDK。

## 官方事件与奖励

- `video_play_request`：实际页面发起播放尝试时回传，接口预取不计入。
- `ep_play`：Player 真正开始播放时回传，同一次请求内暂停恢复不重复计算。
- `minis_ad_show`：官方广告 `show()` 成功时回传，不以加载、关闭或奖励到账替代展示。参数引用当前剧目中前一实际播放剧集。
- `reportEvent` 先做 `canIUse` 检查，失败不阻塞播放或结算。`open_id` 仅来自本次静默登录，在内存使用，不日志化或持久化。
- 没有先前播放剧集的首页 VIP 广告目前跳过剧集型展示事件；正式联调需确认这类入口的官方要求。
- 领取奖励仍必须等待 `onClose` 的 `isEnded === true`，服务端事务负责幂等结算。待领取队列按应用和 Visitor 隔离，避免账号切换时错领。

## 官方 UI 边界

- UI 优先采用官方 [TikTok 短剧播放器接入指南](https://bytedance.larkoffice.com/wiki/B9J3wtpntir3PfkTwY3cSkGwnib) 的 `tiktok-minis-drama-demo.zip` 附件。2026-09-15 核对，文档最后修改于 2026-09-11；附件 SHA-256：`522129c56291bcd0b448685d734a86b617b7c38ee1cbfad17b5b2b9f71a680ac`。
- `DramaCard`、`OfficialIcons`、`BottomNav`、`EpisodeSheet` 和 `official-ui.css` 改编自该附件：发现页采用顶部分类、首推卡片与横向海报列表；剧场采用右侧操作、底部选集栏和白色选集面板。官方提供的是示例源码，不是另一个自动生成全站 UI 的 SDK。
- 登录前后均挂载同一个 `SquarePage`，共用搜索、状态/分类、首推卡片、列表和底部导航；登录提示作为首页状态显示。筛选和已加载的公开分页在登录重试时保留，认证成功后保持筛选。公开收藏及个人导航仅保留当前意图，身份安装完成后才执行；回到 Discover 取消待跳转目标。
- 公开目录使用与 discovery 相同的服务端筛选和分页参数；server 增加完整目录 `tags`，兼容旧服务端时保留已知真实分类，空结果不移除取消筛选的入口。
- 示例未提供业务能力的部分继续使用现有实现：真实 API 搜索、状态与标签筛选、本机收藏/历史、登录恢复、广告解锁、VIP 权益。切集使用现有单 Player 容器，基础播放器操作仍由官方控件提供。
- 适配差异：只展示真实目录，不复制示例虚构互动数或重复剧目；底部仅保留已接通的 Discover、My List、Profile；保留现有 Hash 深链；选集每组 24 集并补齐锁定提示、键盘分页、焦点隔离及恢复；无功能的 More 按钮不进入产品。长按倍速继续使用官方播放器能力，不复制示例自绘倍速层。
- 保留 VePlayer 官方进度条、中央播放和错误状态；选集与倍速继续使用页面已有入口。按官方沉浸式短剧示例关闭会与业务底栏重复的播放、倍速、清晰度、全屏、重播和更多菜单插件，同时关闭 `volume`、`pip`。
- 官方进度条只负责展示与拖动。观看秒数继续通过 `TIME_UPDATE` 按应用和 Visitor 保存到客户端本地，并在播放器就绪后恢复；官方媒资缓存不作为观看历史或跨页面续播数据。
- H5 的上下滑切集和业务浮层必须排除 `.xgplayer-controls`、`.xgplayer-start`、`.xgplayer-replay` 与 `.xgplayer-error` 官方交互区。
- VePlayer 展示官方错误状态；H5 监听 `ERROR`，通过 `userMessage` 展示友好提示，并在重试时重新校验权益和获取最新播放描述符。

## 官方预加载交接

- 初始化与切集、预加载共用 `720p` 默认清晰度，沿用官方示例的有限重试、静音自动播放降级与 `getVideoByToken.needPoster` 官方封面配置；不以剧目封面或业务 `poster` 参数覆盖分集视频封面。
- 有 MSE/MMS 时调用 `prepare({ strategies: { preload: true } })`，首页使用 MANUAL（5 秒），播放首帧后切换 AUTO（前一集、后两集、5 秒）。无 MSE/MMS 时仅预取媒体信息。
- 首页跳转剧场时保留已经开始的预热；播放页拿到当前集首帧才替换官方候选列表。业务 API 对已就绪但未解锁的剧集返回仅供预热的 `preload`，使它也能进入官方相邻集窗口；切集起播仍须取得 `playable`。首次创建 Player 不等待相邻集预加载。
- 身份更换仍清除预加载任务、字节及媒体信息缓存；没有引入示例 mock 数据、播放 Token 或本地模拟模式。

## 日志与错误

观看进度、收藏和历史按应用与 Visitor 在客户端本地保存，不使用消费者写入接口。播放位置以 5 秒节流同步写入本地存储，暂停、切集和退出时补写；重新进入时通过 Player 适配器恢复位置。存储不可用时只在当前实例内存保留，不承诺跨页面恢复。本地记录不是服务端权益凭据。

不建设无人消费的 QoE 自定义事件通道；保留核心播放日志与 TikTok 官方事件回传。

客户端日志只记录流程、阶段、结果、平台媒资标识、耗时和 API `requestId`；不记录 Token、URL、Authorization、Cookie 或原始 SDK 错误内容。页面展示错误必须经过 `userMessage` 封装，非白名单服务端错误统一显示本地化友好降级提示。

## 仪表盘行为采集（2026-09-15）

在现有官方事件回传外，`MetricCollector` 将仪表盘需要的匿名化计数信号发往自有 `/api/v1/metrics`：前台活跃、身份建立后的启动、实际播放开始/结束、激励广告展示/完整观看、插屏展示。应用与用户身份由 API 凭据恢复；正文不携带 OpenID、剧目、集号、位置、媒资 URL 或奖励凭据。没有新增观看进度或历史同步能力。

- 官方 Player 的实际 `onPlay` 与 `onEnded` 驱动统计；预取不计播放，同一过程恢复不重计，重播新建过程。页面切换和账号变化清理计数上下文。
- 展示成功与 `isEnded === true` 分开采集；取消和错误不计完播。原始广告与权益流程继续使用官方适配器和幂领奖，采集失败不会触发额外广告或阻断领奖。
- 前台状态复用网页与 `minis.show` / `minis.hide` 生命周期；跨日活跃每分钟检查，但同日仅发送一次主动活跃信号。
- 队列仅保存在当前页面内存，最多 200 条、每批 50 条、最多三次尝试。原键重试，切换账号丢弃旧队列，刷新关闭页面可能漏报。指标请求不触发静默登录。服务端允许近 24 小时信号和最多 5 分钟前向时钟偏差。
- 先执行 server 的 `sql/add_metric_collection.sql` 并更新 API，再发布 Mini。历史行为无法回填；数据是客户端采集统计，不是 TikTok 官方结算报表。
