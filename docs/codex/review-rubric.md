# 评审准则

## P0

- TikTok Client Secret、Access Token 或 BytePlus 长期凭据被暴露到客户端包中。
- 生产播放绕过 TikTok Minis 官方 Player、消费者权益校验或官方短期播放凭据链路。
- 未完整播放的广告获得权益。

## P1

- 切换剧集时泄漏播放状态，或把进度写入错误剧集。
- 运行页面可以启用模拟播放器、演示数据或自动完成广告。
- 看似数字的平台标识符被强制转换为 JavaScript Number。
- 异步播放器挂载、权益领取或路由任务可以覆盖当前页面状态。

## P2

- 缺少重试、清理、不支持版本状态或聚焦回归测试。
- 修改 API 合同但没有对应仓库的协同记录。
