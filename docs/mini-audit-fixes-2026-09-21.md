## 数据与行为边界

- 没有删除旧 `local-device` 数据，也不自动把无法判断归属的共享记录迁入某个 Visitor。原 Visitor 分区仍可读取；旧共享记录不会再展示。
- F07 采用保守的本页内存降级：存储异常后不自动把整份内存快照写回磁盘，避免覆盖未读到的记录。重新打开页面可读取持久化记录，但故障期间的新修改不承诺跨页面保留。待领取奖励仍使用原有带增删合并的恢复机制。
- 广告完成、领奖和逐集授权约束不变；倒计时、两个广告弹窗的文案与样式不变。没有添加第二套播放器、浏览器模拟广告或服务端进度同步。
- 保留修复开始前的播放封面、切集覆盖层和测试修改；本轮没有以增加遮罩宣称缩短首帧延迟。
- 按工程、播放器、产品策略与 React 异步链路原则，移除的是不必要的串行等待，不跳过授权，也不把 Promise 兑现当作视频首帧。
