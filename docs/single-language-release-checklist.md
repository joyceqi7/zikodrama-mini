# 单语言与无字幕验收

- 消费者界面和错误提示固定英语，管理端固定中文。
- 应用配置和启动响应不包含语言列表；请求不发送语言协商头。
- 剧目、分集及 VIP 文案只使用已保存的主字段；标签展示官方名称。
- 原始音频语言仍是官方内容发布元数据，不作为界面语言设置。
- 官方播放器使用 `lang: "en"`、`autoSubtitle: false` 并忽略 `Subtitle` 插件。
- TikTok 真机验收检查字幕入口不出现、切集和旧版 Token 恢复正常，同时覆盖登录与广告权益。
- 已烧录在视频画面中的文字不受此改动影响；已有平台素材不会因移除功能而被批量删除。

桌面自动化不能代替 TikTok 真机验收。
