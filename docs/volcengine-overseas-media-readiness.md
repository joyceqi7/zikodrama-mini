# 已废弃：旧火山引擎媒资方案

更新日期：2026-09-03

该方案已废弃，不属于新系统的实现依据。新系统没有存量媒资，重新启用独立 BytePlus VOD 服务，并通过 TikTok Media Asset Management 官方接口完成 Album、Episode、审核、线上版本、上下架和授权编排。
